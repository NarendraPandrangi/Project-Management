# 🧩 Jira Clone - Task Management System

A full-stack **Jira-style Task Management** application built with **React (Frontend)**, **Python (Backend)**, and **MySQL (Database)**.

## 🚀 Features

- 📝 Create and manage **projects**, **sprints**, and **tasks**
- 📌 Drag & drop tasks across columns (To Do, In Progress, Review, Done)
- 🧑‍🤝‍🧑 Multiple user support
- ⏱️ Sprint tracking & deadlines
- 📊 Dashboard view for tasks per sprint
- 📂 Backend REST API using Python (FastAPI/Flask)
- 💾 Data stored in MySQL
